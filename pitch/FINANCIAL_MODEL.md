# Five-year financial model (base · bear · bull)

Planning model, not audited statements. Currency USD. Fiscal years end 31 December. First commercial year **FY2027**. Parties never pay. Public self-serve registration is off in production unless explicitly enabled.

**Founder:** Tyler Brasseaux, founder and systems architect.

## Pricing (host pays)

| Motion | Annual | Notes |
|---|---:|---|
| Facilitator practice | $14,400 | 1–3 seats |
| Firm / ADR office | $54,000 | Multi-facilitator host |
| Corporate ombuds / ER facilitation | $84,000 | Organization host |
| Dedicated residency | $160,000 yr-1 | Implementation + host-scoped keys |

No per-party metering (that would create a directory incentive). No speech usage fees.

## Market construction (honest)

ADR professional services (**$9.13B in 2025**, 360iResearch) are **not** Avelis TAM. Avelis is software for the session.

| Layer | Value | Method |
|---|---:|---|
| Software attach on ADR fees | ~$274M | ~3% of $9.13B — tooling that today is Zoom, a portal, or nothing |
| Ombuds / ER live-session tooling | ~$300M | Slice of ER/investigation software used for talks, not case files |
| Law-firm settlement rooms | ~$150M | AmLaw and boutiques on generic video |
| **Working TAM** | **$720M** | Confidential-session software. Estimate. |
| **SAM** | **$115M** | ≈2,400 English-speaking institutional hosts × $48k blended ACV |
| **SOM FY31 (base)** | **$13.2M ARR** | 190 hosts · ~11% of SAM |

## Assumptions

- Evaluation-gated sales; founder-led FY27–28; one AE in FY29
- Blended ACV $38k → $68k as mix shifts to firms and corporate hosts
- Logo churn 8% FY28, 10% thereafter
- NRR 115% from seats inside a host
- Gross margin 78% → 86% (no media archive; room is memory-only)
- Headcount 1 → 3 → 7 → 14 → 24
- Seed $2.0M; first operating profit FY29 in the **base** case

## Unit economics (FY29 base)

- CAC ~$22k fully loaded (AE + founder evaluation)
- ACV $56k mix-weighted
- Gross margin 84%
- Payback ~14 months
- High LTV/CAC is an artifact of high ACV and **no ads**. Volume stays small.

| Use | Amount | Purpose |

| Institutional sales | $500k | One AE, evaluations, design-partner ops |

Capital that requires AI features, a consumer room, or legal-hold on speech is the wrong capital.

## What would break this model

- Adding a transcript, summary, or model on the speech path (forbidden by constitution)
- Self-serve consumer signup as the growth loop
- Treating eDiscovery spend as TAM
- Assuming Zoom-like seat counts
