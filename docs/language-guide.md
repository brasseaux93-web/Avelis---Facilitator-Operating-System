# Language Guide

> Avelis uses factual, institutional, clinical-neutral language.

## 1. Principles

Use language that:

- States system behavior plainly
- Distinguishes live-room content from retained process information
- Avoids emotional promises and legal overstatement
- Avoids implying surveillance, interpretation, or recording
- Makes retention and destruction understandable

## 4. Required disclosures

### Live room

```text
Room messages are delivered live and are not stored by Avelis.
```

### Session close

```text
Closing ends room access and destroys the live room. Messages cannot be recovered.
```

### Retention

```text
Process records and any joint minute are retained until [date and time], then destroyed.
```

### Joint minute

```text
The joint minute is optional. It is separate from the live room and may be exported or wiped.
```

### Destruction

```text
Session records were destroyed. The destruction receipt remains.
```

## 5. Error style

Errors state facts and next actions without reassurance language.

| Avoid | Use |
|---|---|
| “Don’t worry, your data is safe.” | “The action did not complete. No room message was stored.” |
| “We saved your progress.” | “The joint minute draft was updated.” |
| “Your conversation is secure forever.” | “Room messages are not stored by Avelis.” |
| “We can restore this later.” | “Closed-room content cannot be recovered.” |
| “Your privacy is guaranteed.” | “Avelis does not store room messages or audio.” |
