# Accelerator posture (solo founder)

Avelis is built to be taken into a 2026 program **without pretending to be a ten-person company**.

## How to introduce it

One line: **private rooms for difficult conversations — a visible agent, then the talk is gone.**

Not: an AI judge, a Zoom competitor, consumer mediation, a ZK company.

## Why a solo founder is the pitch, not the apology

- One object: the session.
- One speech rule: it is not stored.
- Written constitution, threat model, language guide, and tests in the repo.
- Evaluation-gated sales. No public self-serve register in production.
- Infra is a memory-only room plus an API, not a media archive.

The risk of one founder is real. The mitigation is a **small surface**. Programs that still want a consumer growth loop are the wrong programs.

## 2026 programs this shape fits

| Program | Why it fits | Why it might not |
|---|---|---|
| Y Combinator ($500k / 7%) | AI on real work; compliance-shaped products in RFS | They like speed; we like evaluation |
| a16z Speedrun (up to $1M) | Infrastructure taste; no board seat | 10% on $500k is expensive if they want consumer |
| Techstars ($220k / ≥5%) | Industry verticals (legal, HR, workplace) | Network-heavy; we sell slowly |
| AI Grant | Credits + capital, uncapped MFN | They fund model-first; we fund process-first |

Do not apply as “AI mediator.” Apply as **session infrastructure for talks that must not become a file**, with a disclosed agent that runs named Fisher/Ury moves.

## Diligence they will actually do

1. Can two parties finish an eight-minute session?
2. Is there a transcript path if we grep the repo?
3. Who writes the ledger? (A human. Always.)
4. What remains after purge? (A destruction receipt.)
5. Solo-founder bus factor? (Constitution + tests + narrow object.)

If those five are clean, the rest of the memo is TAM and design partners.
